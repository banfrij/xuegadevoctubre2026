# xuegadevoctube2026

Starter de Xuega Dev con Vite, React, TypeScript, Tailwind CSS y Firebase.

## Inicio rápido

```sh
npm install
cp .env.example .env
npm run dev
```

Completa las variables `VITE_FIREBASE_*` de `.env` con la configuración de tu proyecto de Firebase. Habilita el inicio de sesión con correo y contraseña en Firebase Authentication y configura Firestore para usar la base de datos.

`npm run build` valida los tipos de TypeScript y genera la aplicación para producción.
